# Minishell

## Description
Minishell is a Linux-based shell implemented in C.

It provides basic shell functionalities such as:
- Command execution
- Built-in commands
- Process creation
- Input and output handling
- Signal handling

## Features
- Execute Linux commands
- Handle built-in commands
- Support pipes
- Input/output redirection
- Handle signals
- Environment variable support

## Technologies Used
- C
- Linux
- GCC
- System Calls
